# Talking-head rough-cut starter

This is reusable workflow source. Read the workspace `AGENTS.md`, `shared/WORKSPACE_CORE.md`, `CREATIVE_DNA.md`, and this starter's `README.md` before using it. Confirm `VPL-CORE-1`.

- Keep original media under this starter's ignored `source/` folder. Keep transcripts and proposed cuts under its ignored `work/` folder. Put renders in the ignored workspace `outputs/` folder.
- Do not install packages, models, editor connectors, or services, upload media, connect accounts, spend credits, or publish without Mark's separate authorization.
- The default output is a flattened MP4. Do not claim native timeline control unless the selected editor and a supported route are verified.
- Display the full proposed cut list and wait for Mark's explicit approval before creating an approval record or rendering. Bind approval to the exact cut-list SHA-256. A cut change requires new approval.
- Verify rendered frame count and probe data. Keep technical checks separate from human watch/listen review, creative approval, and publication.
- For a client or named production, create its own project records from `templates/project/` and keep that project's media and work files out of Git.
